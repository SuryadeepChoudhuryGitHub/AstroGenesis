# Textures Directory (`assets/textures/`)

Place OpenGL textures here for rendering 3D bodies and environments.

### Structure Suggestions
- `planets/` (Earth, Moon, Sun surface maps, cloud overlays)
- `skyboxes/` (Space background cubemaps)
- `materials/` (Normal maps, roughness, specular maps)

### Recommended Formats
- PNG / JPEG / TGA / HDR / EXR
