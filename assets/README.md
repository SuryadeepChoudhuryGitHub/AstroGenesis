# Assets Directory Structure

This directory contains all static assets used by the Cosmos 3D Space Physics Simulation.

## Folder Organization

- **`images/`**: UI graphics, logos, icons, screenshots, and general image assets.
- **`textures/`**: 2D/3D OpenGL texture maps (e.g., planet surface maps, diffuse, normal/specular maps, skyboxes).
- **`fonts/`**: TrueType (`.ttf`) and OpenType (`.otf`) font files for Dear ImGui or text rendering.
- **`shaders/`**: GLSL shader files (`.vert`, `.frag`, `.comp`, etc.).
- **`models/`**: 3D object/mesh assets (`.obj`, `.gltf`, `.glb`, `.fbx`).
- **`audio/`**: Sound effects and background audio files (`.wav`, `.mp3`, `.ogg`).
